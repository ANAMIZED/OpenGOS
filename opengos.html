OGOS · v0.3 · APACHE-2.0

What this is

A single-file, no-backend interactive shell for OpenGOS — the open-source agentic MCP server for grants and public-goods funding. Discovery, ranking, lifecycle tracking, grounded drafting, a simulated MCP console, and a 3D knowledge constellation, all in one HTML file. Everything runs locally in your browser; webfonts load from Google Fonts and fall back to system type without a network.
