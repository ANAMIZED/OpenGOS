# Dogfooding OpenGOS

Use OpenGOS on itself: profile the project, rank public-goods vehicles, and draft sponsorship / collective outlines.

## Suggested profile

- **Name:** OpenGOS
- **Pitch:** Autonomous agentic MCP server for grants and public-goods funding, with declared open-source ranking bias.
- **Tags:** open-source, infrastructure, public-goods, mcp

## Suggested vehicles

- GitHub Sponsors
- Open Collective (fiscal host)
- NLnet / open-internet programmes (when calls reopen)
- NSF PESOSE (if eligibility fits)
- OpenSSF / critical-infrastructure funds (by invitation or fit)

## Workflow

1. `upsert_profile` with the fields above
2. `list_public_goods_funding`
3. `list_open_source_relevant_grants`
4. `draft_proposal_outline` for the chosen vehicle
5. Track lifecycle in the interactive shell (`opengos.html`)
