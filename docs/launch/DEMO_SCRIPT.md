2. **8–25s** — Constellation: rotate, tap the gold super-star
3. **25–45s** — Tap a pillar → tool → opportunity; show wiki links
4. **45–70s** — Discover → Public goods → Track → Draft starter
5. **70–90s** — Console `list_public_goods_funding` → close on Constellation

Talking points: grants + sponsorships in one place; open-source bias is explicit; single-file demo + real MCP server from the repo.
